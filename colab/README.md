# Colab 노트북

GPU가 필요한 작업은 **임베딩뿐**이다. 여기서 한 번 계산해 Hub에 올리면
이후 실험은 전부 CPU에서 무료로 돈다.

| 노트북 | 하는 일 | 비용 |
|---|---|---|
| `embed_nvembed.ipynb` | 후속 질의(R1·R2) + PopQA를 NV-Embed-v2로 인코딩 | L4 30분, 2~3 단위 |

## 왜 필요한가

**후속 질의** — 지금까지 2홉 검색을 BM25로 한 것은 후속 질의를 임베딩할 방법이
없어서였다(NV-Embed-v2는 7.85B라 로컬 19.3GB 메모리에 안 들어간다).
같은 공간에 넣으면 dense로 2홉을 돌릴 수 있고 그것이 2홉 품질을 직접 올린다.

**PopQA** — PropRAG이 보고하는 네 번째 데이터셋(Recall@5 55.3).
단일홉이라 우리 방법이 힘을 못 쓰는 자리지만, 빼면 유리한 것만 골랐다는 말을 듣는다.

## 주의

- **런타임은 L4 또는 A100.** T4(16GB)는 fp16 가중치 15.7GB만으로 꽉 차서 실패한다.
- 보안 비밀에 **쓰기 권한 있는** `HF_TOKEN`을 넣을 것.
- 인코딩 설정은 `neurographdb/job_e1.py`의 `encode()`와 **한 글자도 달라선 안 된다**.
  다르면 새 벡터가 기존 캐시와 같은 공간에 있지 않게 된다.
  마지막 셀이 기존 캐시와의 코사인으로 이것을 검증한다(0.999 이상이어야 한다).
- 이미 있는 산출물은 건너뛴다. 중간에 끊겨도 다시 돌리면 된다.
